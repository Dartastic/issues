# Dartastic — public support inbox

This repository is the public-facing inbox for everything Dartastic.
Our product code lives in private repositories; this one is where
you (customer, prospect, contributor, curious passer-by) tell us
what you need.

## I want to…

| | Where to go |
| - | - |
| Report a bug | [Open an Issue](../../issues/new/choose) → "Bug report" |
| Request a feature | [Open an Issue](../../issues/new/choose) → "Feature request" |
| Ask a "how do I…" question | [Open a Discussion](../../discussions) → Q&A |
| Share what you built | [Open a Discussion](../../discussions) → Show & Tell |
| Ask about licensing, pricing, or your subscription | [support@dartastic.io](mailto:support@dartastic.io) |
| Report a security issue (please don't open a public issue) | [security@dartastic.io](mailto:security@dartastic.io) — see [SECURITY.md](./SECURITY.md) |

## What lives here

- **Issues.** Bug reports, feature requests, license/quota questions.
- **Discussions.** Q&A, show-and-tell, ideas not yet shaped into
  feature requests.

## What does NOT live here

- **Product source code.** Dartastic Pro is closed-source; the
  engine, the symbolizer, the dashboards, and the per-customer
  build pipeline all live in private repos. You don't need to see
  them to use Dartastic, and we don't need you to see them to
  help you.
- **Private support conversations.** If your question involves a
  license key, a billing question, or anything you wouldn't
  publish on the public internet, email
  [support@dartastic.io](mailto:support@dartastic.io) instead.

## Response expectations

- **Issues:** triaged within 1 business day. Real fix windows vary
  by severity — critical bugs get a same-day patch; smaller items
  land in the next sprint.
- **Discussions:** read within a business day; not all questions
  get an answer the same day. Other community members often
  answer faster than we do.
- **support@dartastic.io:** within 1 business day for Pro
  customers; Hosted customers see SLAs on their plan.

## Code of conduct

Be kind, be specific, be patient. The
[contributor covenant](./CODE_OF_CONDUCT.md) applies. Off-topic
or hostile posts get hidden; repeat offenders get blocked.

## About Dartastic

The shortest version: **production OpenTelemetry for Dart and
Flutter, with a native engine that does things no other Flutter
APM can do.** Per-widget jank attribution, persistent crash
queue, in-process PII scrubbing, hosted single-tenant
observability. Pricing + product detail at
<https://dartastic.io>.
